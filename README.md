# 《末班車！月台大混亂》進階挑戰版 v2.0

繁體中文、單手操作、45秒一局的網頁單機遊戲。純 HTML / CSS / JavaScript，毋須帳戶與外部素材。

## 新版挑戰
- **三種難度**：普通、挑戰、極限。難度影響速度、發車間隔、轉軌冷卻、失誤次數。
- **🚄 特快列車**：綠色車身標示 `EXP`，速度更快；正確送達可得加分。
- **⚡ 雙車連發**：偶爾連續發出兩班車，需要快速預判下一次切換。
- **轉軌冷卻**：切換月台後短時間不能再切換；挑戰及極限模式更長。
- **連續成功**：Combo提高得分，連續送對6班可啟動慢動作。
- **尖峰時刻**：全體列車暫時加速。
- **結算資訊**：得分、成功調度班次、最高連擊和稱號。

## 操作
- 手機：按底部 🌸 花站 / ⭐ 星站 / 🌙 月站。
- 電腦：鍵盤 `1`、`2`、`3`；`空白鍵` 使用慢動作；`P` 暫停。
- 車頭的圖案代表真正目的地。列車抵達中央岔路前，必須先切換到目標月台。

## GitHub Pages
1. 下載 ZIP 並解壓。
2. 在 GitHub repository 根目錄放入 `index.html` 和 `README.md`。
3. 若已存在同名檔案，請先在 GitHub 直接編輯並替換內容，或移除舊檔再上傳。
4. Commit changes。若已開啟 Pages，通常會從 `main` / `(root)` 自動重新部署。

## 藝術理念
隨著成功調度，城市的建築窗戶會逐漸亮起，表達微小的個人決定如何改變共同生活的城市。新版的節奏加快與多車連發，讓觀眾感受城市系統在壓力下的秩序與失衡。
